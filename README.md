# Free Tabletop Gamers Printables Kit

Fillable, printable character sheets, session notes, an NPC tracker, and a rules cheat-sheet for tabletop RPG and board game night.

No account needed. No game assets included. Print at home or save as PDF from your browser.

## What's included

| File | Description |
|------|-------------|
| `character-sheet.html` / `.md` | Fillable character sheet: abilities, HP, skills, attacks, equipment, coin |
| `session-notes.html` / `.md` | Session notes: summary, key events, NPCs met, loot, quest log, next-session hooks |
| `npc-tracker.html` / `.md` | NPC tracker: quick-reference table, detail cards, relationship map, voices |
| `rules-cheatsheet.html` / `.md` | Rules cheat-sheet: core loop, combat, conditions, skills, DCs, house rules |
| `index.html` | Kit landing page with links to every printable |

## How to use

1. Open any `.html` file in your browser (double-click, or `file://`).
2. Fill in the fields on screen.
3. Press **Ctrl+P** (Cmd+P on Mac) → choose your printer or **"Save as PDF"**.
4. Print at 100% scale on US Letter or A4 paper. In the print dialog, turn **background graphics off** for cleanest results.

The Markdown (`.md`) files are plain-text source versions you can edit, print from any Markdown viewer, or include in your own campaigns.

## No game assets

This kit contains generic, system-neutral templates only. No art, logos, stat blocks, spells, monsters, or proprietary game content is included. Bring your own game.
